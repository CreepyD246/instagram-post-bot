# instagram-post-bot
This is an Instagram post bot that uses Ollama and other AI tools to create automatic Instagram posts - the images will be generated by AI.

For a full walkthrough and explanation, refer to the video - https://youtu.be/5PXQmqXKvNE

## Dependencies
`pip install diffusers transformers accelerate safetensors ollama schedule`

**NOTE ON TORCH:**
`torch` is also required for this project.
Since torch has 2 versions (a CPU version and a GPU version) there are 2 options when installing.
The CPU version is a simple `pip install torch`
For the GPU version, please copy the install command generated using your customizable parameters - https://pytorch.org/get-started/locally/
